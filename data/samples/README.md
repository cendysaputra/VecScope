# Sample images

This folder is filled by `python scripts/download_samples.py` and is git-ignored
(except this file). The images come from the Hugging Face dataset
[`huggingface/documentation-images`](https://huggingface.co/datasets/huggingface/documentation-images),
licensed **CC BY-NC-SA 4.0** — fine for a non-commercial demo with attribution.

You can also drop your own `.jpg` / `.png` files here, or upload images in the app.
